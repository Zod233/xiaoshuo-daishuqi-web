# 世界规则

水浒没有境界体系，只有**武力梯队、身份权限、官府追究**三条线。裁定任何行动，先过这三条。

## 一、武力梯队

| 梯队 | 代表 | 能做什么（硬指标） | 门槛 |
| --- | --- | --- | --- |
| 绝顶 | 卢俊义、关胜、林冲、呼延灼、武松、鲁智深 | 独战两三名好手不败；乱军中来去；一人可挡十数差役 | 天生神力 + 十年以上苦练 + 有名师或军中经历 |
| 上等 | 秦明、花荣、杨志、史进、孙立、石秀 | 独战一名好手不分胜负；能带十人小队 | 军中或江湖历练多年 |
| 中等 | 各县都头、寨主、教师、庄客头目 | 打三五个寻常人；擅一项专长（水性、暗器、偷窃） | 行伍出身或拜师学艺 |
| 寻常 | 差役、兵丁、脚夫、百姓 | 打一个；遇好汉一击即倒 | 无 |

**绝顶不等于无敌**：体力、伤、围殴、地形、暗器都能杀绝顶。鲁智深在十字坡也差点被麻翻。

## 二、道术（极少数）

| 项 | 内容 |
| --- | --- |
| 谁会 | 公孙胜（罗真人门下，五雷天心正法）、高廉（高唐州）、包道乙（方腊部）、樊瑞（混世魔王，后拜公孙胜） |
| 能做什么 | 呼风唤雨、驾雾、飞剑、纸人纸马；能乱军心，不能移山填海 |
| 门槛 | 必须有师承、符咒、设坛，事前斋戒；仓促之间用不出来 |
| 代价 | 折损精神，用后数日虚弱；滥用者多不得善终 |
| 谁能破 | 同门道术、污秽之物、近身强攻。**寻常好汉遇道术，只能躲、逃、冲近身** |

## 三、上限案例（判定尺）

| 编号 | 谁 | 出处 | 做了什么 | 后果 |
| --- | --- | --- | --- | --- |
| U-01 | 武松 | 第 23 回 景阳冈 | 醉后徒手打死吊睛白额虎 | 名震阳谷，做了都头 |
| U-02 | 鲁智深 | 第 7 回 大相国寺菜园 | 倒拔垂杨柳 | 泼皮拜服 |

**尺子用法**：玩家任何一击不得超过 U-01/U-02 的物理量级；要看「一人挡百人」，先给地形、器械、体力三条理由，缺一条就打折。

## 五、谁在管

- 官府：县有知县、押司、都头、牢子；州有知府、通判；路有安抚使、提刑。杀官、劫牢、私藏军器即「谋反」，通缉令下到邻州。
- 江湖：讲「义气」与「名声」，实际按实力与银钱排座次。梁山有「山规」（第 20 回后立），但执行靠宋江的威信与各头领自守。
- 寺院道观：有田产、有度牒，是逃亡者最好的隐身之处（鲁智深、武松都曾出家）。

## 七、制度与礼法

| 项 | 内容 |
| --- | --- |
| 县衙人事 | 知县一人，押司数人（宋江即押司，管文书），都头二三人（管缉捕），牢子、节级十数人 |
| 见官礼 | 百姓见知县跪；吏员揖；同僚拱手。都头在知县面前只能站 |
| 律法红线 | 杀人者斩（可赎买「斗殴误伤」）；劫囚、劫纲、聚众即「谋反」，株连 |
| 刺配 | 脸上刺字，押解到牢城营服苦役；刺配者终身带「贼配军」名 |
| 女人的位置 | 不能当差、不能科举；可掌家财、开店、行院卖艺；被污名者（如潘金莲）无立身之地 |
| 度牒 | 出家可得合法身份，躲罪；度牒要钱买或有人情 |

## 八、经济与物价

| 项 | 价 |
| --- | --- |
| 一顿粗饭 | 五至十文 |
| 一壶酒 | 二十至五十文 |
| 一日脚力钱 | 三十至五十文 |
| 一匹劣马 | 十至二十两 |
| 好马（照夜玉狮子一类） | 数百两，且有价无市 |
| 县城一间小屋 | 数十两 |
| 买通一个牢子 | 三两至十两 |
| 生辰纲 | 十万贯金珠（一贯约千文，此数相当于一州岁入，故称「纲」） |

〔待核〕宋代银钱比价各时不同，书中多用「两」「贯」混称，本设定集按「一两≈一贯≈千文」粗算。

## 九、语言

| 身份 | 说话特征 |
| --- | --- |
| 官 | 自称「下官」「卑职」，称对方「上宪」「大人」，句子整，套话多 |
| 吏 | 「小的」，夹杂公文腔，见上官就矮半截 |
| 江湖 | 「俺」「洒家」「兄弟」，粗直，讲「义气」「招架」 |
| 百姓 | 「小人」「老身」，短句，多是求告 |
| 僧道 | 「贫僧」「贫道」，半文半白 |

## 十、判定速查

| 问题 | 答 |
| --- | --- |
| 这个身份能不能进这个门 | 都头进不了知县后堂；牢子能进牢房；百姓进不了衙门二堂 |
| 这个能力能不能做到 | 对照第一节梯队 + U-01 |
| 要付什么代价 | 武力：体力、伤、暴露；道术：虚弱、折寿；官面：通缉、刺配 |
| 官府会不会管 | 命案三日内上报；劫囚当日即闭城 |
| 消息会不会传出去 | 县城当日传遍，跨州三日，东京十日 |
