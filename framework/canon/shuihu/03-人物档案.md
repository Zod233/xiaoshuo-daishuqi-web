## 单人条目

### P-01 宋江

| 项 | 内容 |
| --- | --- |
| 出身与身份 | 郓城县押司，管文书；家中务农，有弟宋清；人称「及时雨」「孝义黑三郎」 |
| 要什么 | 兄弟活路 + 一个「忠义」的名分。**招安是他的志向，不是临时起意** |
| 能力边界 | 上等武力；真正的本事是散财、记人情、让人为他死 |
| 秘密 | 私放晁盖（第 18 回）；浔阳楼反诗；对晁盖之死有说不出口的轻松 |
| 说话方式 | 自称「小可」「宋江」，句句带「兄弟」「义气」，先认错再劝人 |
| 关系 | 晁盖：救命恩人兼前任；吴用：脑子；李逵：刀；卢俊义：招牌；高俅：不死不休又要招安 |
| 被质问时 | 「兄弟这话重了，宋江若有半点私心，天诛地灭。」——然后转开话题 |
| 会不会杀人 | 不会亲自动手，但会让人去死；杀阎婆惜是失手后的灭口 |
| 原著结局 | 受招安 → 征方腊 → 封楚州安抚使 → 饮御赐毒酒，怕李逵造反，骗他同饮（A-05） |

### P-02 晁盖

| 项 | 内容 |

## 纪律

- 动机只写书里写明的；自己补的解释标「旁白理解」，另起一行。
- 不许为剧情方便让人物改志：宋江不会因一番话放弃招安，林冲不会因一次恩情不恨高俅。
- 人物不是工具人：他也有自己的事要忙，不会随叫随到。
