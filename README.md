# 小说带入器 · 网页版

和豆包版**同一套框架**（同一份旁白纪律、同一份设定集、同一套三问与结算），区别只有两点：

1. 在浏览器里玩，不用切到豆包；
2. **模型接口由你自己填**——你选哪家、用哪个模型、用自己的 Key，都行。

## 怎么开

**双击 `小说带入器.html` 就行。** 不需要装 Python，不需要开服务，不需要联网装依赖。

页面自带一本公版示例（《水浒传》）、一张角色卡（陈砚）。第一次进来点左下角「模型接口设置」，填三项：

| 项 | 填什么 | 例 |
| --- | --- | --- |
| 接口地址 | OpenAI 兼容的 base_url，末尾带 /v1 | `https://api.deepseek.com/v1` |
| 模型名 | 那家的模型 id | `deepseek-chat` |
| API Key | 你自己的 Key | `sk-…` |

点「保存并测试」会发一次极短请求，通没通当场看得见。Key 只存在你这台电脑的浏览器里，不上传、不入库、不进对话记录。

**直连能不能成，取决于那家接口允不允许浏览器跨域。** 实测：DeepSeek、Kimi、硅基流动、通义千问放行；智谱 GLM 目前会拦。被拦时页面会明确告诉你，换一家即可。

## 怎么玩

1. 左侧选世界与角色，点**开局**。
2. 第一轮它先问三句：我是谁／我这一场想先办成什么／我这一趟想得到什么。答完它才写场景。
3. 之后直接说你要做什么。判定默认隐形，只有「这世界做不到」或「代价很大」时它才给一句理由。
4. 一场结束点**结算本场**：按四件事给摘要（角色档变化／行动线／预期板／一句世界线），摘要进下一轮上下文。
5. **导出记录**出 Markdown，方便留档。

## 两个版本，按需要选

| 版本 | 文件 | 要不要 Python | 适用 |
| --- | --- | --- | --- |
| 单文件（默认） | `小说带入器.html` | 不要 | 双击就玩；接口需允许跨域 |
| 本地服务 | `serve.py` ＋ `web/` | 要 | 想接不放行跨域的接口（如智谱）、或想换小说时省事 |

本地服务版：`python serve.py`，浏览器打开 `http://127.0.0.1:8765/`。请求经本机转发，不受跨域限制。

## 换小说

- 单文件版：把六件套放进 `framework/canon/<id>/`，跑一次 `python build_standalone.py` 重新生成（这一步需要 Python，只是给自己加书时用）。
- 本地服务版：放进去刷新页面，世界下拉里就多一项。

角色卡放 `framework/characters/<id>/角色卡.md`。

> 在版小说**不要**放进公开仓库；本机自己玩没问题。

## 文件都是什么

```
网页版/
├── 小说带入器.html           ← 双击这个（构建产物，已内联 CSS/JS/设定集）
├── build_standalone.py       把 web/ + framework/ 打成上面那个单文件
├── serve.py                  可选的本地服务版
├── web/                      前端源码（纯原生，无构建依赖）
│   ├── index.html
│   ├── app.js                对话、设置、结算、导出
│   └── style.css
└── framework/                框架本体（与豆包版同源）
    ├── narrator/             身份、纪律、三个人设
    ├── canon/shuihu/         公版示例设定集
    └── characters/           示例角色卡
```

改完前端要重新跑 `build_standalone.py`，否则单文件版还是旧的。

## 现在的边界（说清楚，免得当 bug 报）

- **不流式**：整段回来才显示，长回复有几秒空窗。
- **没有账号、没有云存档**：记录在浏览器里，换浏览器或清缓存就没了，靠「导出记录」留。
- **结算靠手动点**：不会自动每场记账。
- 只带一本公版书；其余世界自己导入。
- 单文件版被接口跨域拦住时，页面会提示换哪几家，或改用本地服务版。
